# opencode-jevcode

An OpenCode v2 plugin that adds a `jevCode` primary agent. For each prompt sent to `jevCode`, Jev (TypeSafe's
System One decision model) chooses the coding model, skills, tool groups and relevant context. OpenCode's coding
LLM does the work. Other agents (`build`, `plan`, custom) are not changed.

**Status: work in progress.** Not ready for use yet.
